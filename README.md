# Terranova

Terranova is an environmental innovation project created by members of Junior Achievement Nigeria (JAN).

The landing page presents the project's vision, the environmental problem it addresses, its operating model, alignment with relevant UN Sustainable Development Goals, and WasteLens — Terranova's intelligence and operations layer.

## WasteLens

The working WasteLens prototype demonstrates predictive hotspot analysis, collection forecasting, AI-assisted operational recommendations, waste-event monitoring, image-based computer-vision prototyping, node monitoring, reporting, and circular-economy routing.

- Prototype: https://michaelkage.github.io/wastelens-dashboard-prototype/
- Repository: https://github.com/michaelkage/wastelens-dashboard-prototype
